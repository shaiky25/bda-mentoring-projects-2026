# BDA Mentoring Projects (2026)

5 short-duration, industry-aligned projects for student batches (3-4 students each). Each is completable in ≤10 hours and has parallel R and Python skeletons with identical pipeline stages — pick whichever language your batch is using.

Pick **one** project folder below, clone this repo, and work only inside that folder.

| # | Project | Domain |
|---|---------|--------|
| 1 | [project1-diabetes](project1-diabetes/) | Healthcare — diabetes risk screening |
| 2 | [project2-amazon-sentiment](project2-amazon-sentiment/) | E-commerce — review sentiment analysis |
| 3 | [project3-crop-recommendation](project3-crop-recommendation/) | Agriculture — crop recommendation from soil data |
| 4 | [project4-rain-australia](project4-rain-australia/) | Meteorology — rain prediction |
| 5 | [project5-online-retail](project5-online-retail/) | Retail/finance — customer spending patterns |

## Getting started

1. Clone this repo.
2. Open your assigned project's folder and read its `README.md` for the dataset download link.
3. Inside it, pick `implement_in_python/` or `implement_in_R/` (whichever your batch is using) and follow that folder's `README.md` — it covers package install, where to put the dataset, and how to run the skeleton.
4. Implement every function marked "Not implemented" in `analysis.py`/`analysis.R` — **do not change any function signature**.
5. Grading criteria (same for all 5 projects): data clean-up, feature selection, visualization. The optional "stretch" model stubs are not required.
